# KUVORE

🌐 **Disponível em:** [kuvore.vercel.app](https://kuvore.vercel.app/#/login)

## Execução

```bash
flutter pub get
flutter run -d chrome
```

```bash
flutter devices
flutter run -d <device>
```

## Análise

```bash
flutter analyze
```

## Firebase

O projeto utiliza Firebase Authentication e Cloud Firestore.

A configuração do Firebase está em:

```text
lib/firebase_options.dart
```
